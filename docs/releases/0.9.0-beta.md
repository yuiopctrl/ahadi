# Ahadi 0.9.0 Beta

## Scope

This release introduces controlled beta rollout operations for Ahadi:

- Registration modes: open, invite-only, and paused.
- Hashed beta invitation codes with server-side validation and consumption after onboarding.
- Platform beta dashboard with rollout status, invitation list, recent registrations, activation funnel, and tenant health signals.
- Tenant and platform support request workflows.
- Product feedback collection and frontend error reporting.
- Feature flags with tenant-aware server enforcement for balance reminders, WhatsApp lists, report exports, member statement PDFs, and support requests.
- Version visibility for web/API release channel checks.

## Operator Notes

Apply `supabase/migrations/030_beta_rollout_support_operations.sql` before enabling invite-only mode. Existing tenant login and platform owner login remain available while registration is paused or invite-only.

Full beta readiness still depends on applying migrations in order, verifying Supabase RLS/RPC execution in the target project, and running an end-to-end registration/support/report workflow against the deployed environment.
